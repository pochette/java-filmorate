# 🎬 Filmorate

Backend-приложение для хранения, поиска и рекомендации фильмов.

Проект разработан в рамках курса **«Java-разработчик» Яндекс Практикума** и представляет собой REST API для работы с фильмами, пользователями и рекомендациями.

---

## 🚀 Возможности

* 👤 Управление пользователями
* 🎥 Добавление и редактирование фильмов
* ❤️ Система лайков
* 🔥 Получение списка самых популярных фильмов
* 🤝 Добавление друзей
* 📚 Работа со справочниками (жанры, рейтинги MPA)
* ✅ Валидация данных
* ⚠️ Централизованная обработка ошибок
* 🗄️ Хранение данных в PostgreSQL
* 🧪 Покрытие функциональности тестами

## 📁 Архитектура проекта

```text
src
├── controller
├── service
├── repository
├── model
├── dto
├── mapper
├── exception
├── validation
└── config
```

Проект построен по классической многослойной архитектуре:

* **Controller** — обработка HTTP-запросов;
* **Service** — бизнес-логика;
* **Repository** — работа с базой данных;
* **DTO / Mapper** — обмен данными между слоями;
* **Exception** — централизованная обработка ошибок.

---

## ⚙️ Основной функционал

### Пользователи

* создание пользователя;
* обновление данных;
* получение списка пользователей;
* получение пользователя по ID;
* добавление и удаление друзей;
* получение списка общих друзей.

### Фильмы

* создание фильма;
* обновление информации;
* получение фильма по ID;
* получение списка фильмов;
* постановка и удаление лайков;
* получение наиболее популярных фильмов.

### Дополнительные возможности

* справочник жанров;
* справочник рейтингов MPA;
* валидация входных данных;
* обработка исключений.

## ▶️ Запуск проекта

### Клонирование

```bash
git clone https://github.com/pochette/java-filmorate.git
```

### Сборка

```bash
mvn clean install
```

### Запуск

```bash
mvn spring-boot:run
```

После запуска приложение будет доступно по адресу:

```text
http://localhost:8080
```
